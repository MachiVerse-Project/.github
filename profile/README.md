# MachiVerse Project

> **「世界を作る」のではなく、「世界がそうなった理由」までシミュレーションする。**

MachiVerse Project は、エージェントベース大規模世界シミュレーション **MachiVerse** を開発するオープンソースプロジェクトです。

MachiVerse は、都市・住民・自然環境を最初から配置された静的な状態として扱うのではなく、時間の経過、個々の主体の行動、自然環境と人間社会の相互作用によって現在の世界が形成されていく過程そのものを扱うことを目指しています。

## MachiVerse が目指すもの

- **因果と歴史を持つ世界** — 現在の状態だけでなく、そこへ至った過程をシミュレーションする
- **エージェントによる社会** — 住民などの主体がそれぞれの状態と行動を持ち、世界へ影響する
- **自然と社会の接続** — 地形、水域、植生などを背景ではなく社会へ影響する世界状態として扱う
- **再現可能なシミュレーション** — 同一条件から同一結果へ収束できる決定論的な実行を基本契約とする
- **世界の内側への参加** — 将来的には「ダイバー」として、世界の外から操作するのではなく住民の一人として参加できる体験を目指す

実装済みの範囲、現在開発中の内容、将来構想については、MachiVerse 本体リポジトリの README と ROADMAP を正本として確認してください。
