# MachiVerse Project `.github`

このリポジトリは、MachiVerse Project の Organization プロフィールと、Organization 配下のリポジトリで利用する既定のコミュニティファイルを管理します。

- Organization プロフィール: `profile/README.md`
- 共通コントリビューションガイド: `CONTRIBUTING.md`
- 共通行動規範: `CODE_OF_CONDUCT.md`
- 共通セキュリティポリシー: `SECURITY.md`
- 共通サポート案内: `SUPPORT.md`
- 共通 Issue テンプレート: `.github/ISSUE_TEMPLATE/`
- 共通 Pull Request テンプレート: `.github/pull_request_template.md`

各リポジトリに同種のファイルが存在する場合は、そのリポジトリ固有の内容を優先します。
